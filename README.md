# TechSpeak

TechSpeak is a classroom vocabulary-practice pilot for Region 10 IT Foundations.

Current pilot: **v0.2.1 / Year 1 OC39 — Tools, Safety, and Bench Procedures**.

## Student workflow
1. Open the hosted TechSpeak site.
2. Create a local profile using a first name, initials, or class ID.
3. Enter the instructor launch code (for example `39-SAF-Q5`).
4. Select **Start Today’s Practice**.

## Privacy / pilot architecture
Student profiles and mastery data are stored only in the browser using localStorage. No student progress is sent to GitHub or to a server.

## Pilot note
This repository is intended to host the static classroom pilot. It contains no student records.
